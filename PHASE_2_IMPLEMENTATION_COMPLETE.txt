GET /api/stock/snapshots              → All products (paginated)
GET /api/stock/snapshots/:id          → Single product
GET /api/stock/:productId/ledger      → Movement history
GET /api/stock/batches                → All batches (FEFO)
GET /api/stock/:productId/batches     → Product batches
GET /api/stock/expiry-alerts          → Expiring batches
GET /api/stock/reorder-alerts         → Low stock products
GET /api/stock/valuation              → Total stock value
GET /api/stock/events                 → SSE real-time stream

🔄 REAL-TIME UPDATE FLOW

User Action (Sale) 
    ↓
Stock Command Service
    ├─ Insert event into stock_ledger
    ├─ Update stock_snapshot (atomic)
    ├─ Update stock_batches (FEFO)
    └─ Broadcast SSE update ◄── NEW!
        ↓
SSE Manager
    └─ Send to all clients in shop
        ↓
Browser (EventSource)
    └─ useStockEvents hook receives event
        ↓
StockContext updates local state
    ↓
UI re-renders automatically
    ↓
All users see updated stock instantly! ✨
